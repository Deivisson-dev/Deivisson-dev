## About

Software Developer at **Prefeitura de Arapiraca**, building and maintaining municipal
platforms that serve public administration. Computer Science student at
[**UFAL**](https://ufal.br) with hands-on experience in Laravel, Vue.js, React and
DevOps workflows including Docker and CI/CD. Passionate about open source and about
turning complex government requirements into clean, functional software.

role:      Software Developer @ Prefeitura de Arapiraca

interests: open source, developer tooling, clean architecture
